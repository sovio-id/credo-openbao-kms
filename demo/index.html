Credo × OpenBao
Key management demo

OpenBao Transit + KV v2 fallback

Every Credo key type, one OpenBao backend.

Create, import, sign, verify and delete keys through Credo's 0.7 KeyManagementService API. OpenBao Transit holds Ed25519, NIST EC and RSA keys; a KV v2 mount holds secp256k1 and X25519; the Node.js backend handles randomness and AES-GCM. DIDs and X.509 certificates are issued from the same keys.

How to read this demo

Start in , generate or import any key type, then use . The key catalog is kept in this browser's localStorage; the keys themselves live in OpenBao or SQLite. Use and to see Credo consume the same KMS keys.

Keys

Generate a key inside OpenBao, or import an externally generated JWK through Transit BYOK. secp256k1 and X25519 use the KV v2 fallback; AES-256 is handled by the Node.js backend.

Random & symmetric crypto
